MAYA · 03

Long-horizon reasoning

The agent loop converged.

Models can now sustain a coherent goal across thousands of steps — keeping state, asking for clarification, revising plans mid-execution. The interesting agents aren't bigger models; they're tighter loops.

MAYA · 04

The bottleneck moved

Models aren't the constraint anymore.

  • Schema design beats prompt engineering
  • Eval coverage beats raw parameter count
  • Trust boundaries beat capability ceilings
  • Most agent failures are tool-shaped, not model-shaped
MAYA · 05

Open questions

  • Can humans meaningfully audit a 10k-step plan?
  • Who writes the spec the agent is aligned to?
